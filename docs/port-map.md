# Python → C# port map (0.4.5 → 0.5.0)

Generated by Phase 0 stage 3 from `autosourcarr/app` of 0.4.5 and the stage-26 C# tree after the feature-folder restructure. Every module, every `AutoSourcarrService` method and every HTTP route has a C# target. **exists** = a stage-26 class already covers it (porting = wiring + the missing behaviour); **partial** = some of it exists; **new** = written in the named phase; **dropped** = not carried over (reason given). Targets are folders under `src/AutoSourcarr.Core/` unless the folder is `Api` or `Host`. Phase numbers follow the conversion plan.

Counts: 84 modules, 470 service methods (+131 nested helpers that port inside their parent method, +18 module-level helpers, +2 helper classes), 246 routes in 12 modules.
