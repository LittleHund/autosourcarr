    Authelia preference identity

    Authelia preference identity
    Checking forwarded headers…
    

    

    NGINX / Nginx Proxy Manager forwarding example
    auth_request_set $user $upstream_http_remote_user;
auth_request_set $email $upstream_http_remote_email;
auth_request_set $groups $upstream_http_remote_groups;
proxy_set_header Remote-User $user;
proxy_set_header Remote-Email $email;
proxy_set_header Remote-Groups $groups;
    These are the exact variables/headers used by the existing AutoSourcarr Authelia/Nginx Proxy Manager block. Access AutoSourcarr through that proxied hostname; opening the backend IP/port directly bypasses Authelia, so no Remote-User header can exist.
